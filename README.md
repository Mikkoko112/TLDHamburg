# CiS Projekt 2024 "Ampelschaltung"


## Data files

Large input datasets are not tracked in this Git repository. They are stored separately in Proton Drive to keep the repository manageable.

Download the required files from [Proton Drive] https://drive.proton.me/urls/WKK7NN0EG0#rYvFKk6F6VIM and place them at their original paths:

- `tldhamburg/control/data/hamburg.gml`
- `tldhamburg/control/data/shHamburg.gml`
- `tldhamburg/control/data/shHamburgCopy.gml`
- `signal_observations/observations_all_datastreams.json.gz`

These files are excluded from version control. The repository will not work as intended until the required datasets have been downloaded and placed in the correct locations.
